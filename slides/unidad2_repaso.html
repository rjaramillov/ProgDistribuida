03

Taller de bytes

Fue el tema más bajo del parcial. Arma un mensaje y mira qué bytes viajan por la red. Los nombres de los campos no viajan: solo el número de campo, el tipo y el valor.

La regla, en 3 líneas

Etiqueta = número de campo × 8 + tipo. Para texto (string) el tipo es 2; para números enteros y bool el tipo es 0.

Texto: etiqueta, luego el largo (cuántos bytes mide) y luego cada letra en hexadecimal.

Número: etiqueta y luego el valor (sin largo). Un campo vacío, en 0 o en false no se escribe.

Decimal a hexadecimal, rápido

CampoCuenta (texto)DecimalHex
11 × 8 + 2100a
22 × 8 + 21812
33 × 8 + 2261a
44 × 8 + 23422
55 × 8 + 2422a

Para pasar a hex: divide entre 16. 26 = 1 × 16 + 10 → 1a (10 es a, 11 b… 15 f).

04

Veo este error… ¿dónde está?

Son los errores que salieron en los laboratorios, en el reto y en el parcial. Todos se reprodujeron en un Codespace para que el mensaje sea el mismo que verías tú.

1 · ¿Es un error de Python?ModuleNotFoundError, NameError, AttributeError, ValueError, TypeError: el problema está en el programa que lo imprimió o en su entorno. Ni siquiera llegó a la red.
2 · ¿Es un código gRPC?Ya salió por la red. Lee el código: UNAVAILABLE no llegó al servidor · UNIMPLEMENTED el servidor no tiene ese método · UNKNOWN o INTERNAL el servidor tiene un bug.
3 · ¿Es INVALID_ARGUMENT o NOT_FOUND?No es un bug: el servidor funciona y te avisó con context.abort. Lo que falta es atraparlo en el cliente con try/except.

06

Desde archivo en blanco: una biblioteca

En los laboratorios y en el reto el código venía a medias. Aquí empiezas con una carpeta vacía en tu Codespace. Abre las pistas solo si te atoras, y la solución solo cuando ya lo intentaste.

Lo que vas a construir

Un servicio Biblioteca en el puerto 50070 con dos rpc:

  • BuscarLibro (unario): recibe una clave y regresa un libro. Clave vacía → INVALID_ARGUMENT. Clave que no existe → NOT_FOUND.
  • ListarPorAutor (streaming del servidor): recibe un autor y regresa sus libros, uno cada medio segundo.

Datos: L001 Pedro Páramo, Rulfo, 124 · L002 El llano en llamas, Rulfo, 170 · L003 Aura, Fuentes, 61.

Al final, tu cliente debe imprimir esto:

=== 1 · Un libro que existe === Pedro Paramo - Rulfo - 124 páginas === 2 · Un libro que no existe === Error: NOT_FOUND - No existe el libro L999 === 3 · Todos los libros de Rulfo (streaming) === Llegó: Pedro Paramo Llegó: El llano en llamas

Paso 1 · El contrato biblioteca.proto

  • Empieza con syntax = "proto3"; y un package.
  • Un service Biblioteca con los dos rpc. El de listar lleva stream en lo que regresa.
  • Tres message: la petición por clave, la petición por autor y el libro (clave, título, autor, páginas).
  • Cada campo con su tipo y un número distinto dentro de su mensaje; cada línea termina en ;.
Pista 1
Fíjate en la forma: rpc Nombre (MensajeQueRecibe) returns (MensajeQueRegresa); y, para el streaming, returns (stream Libro). Las páginas son un número entero: int32.
Ver la solución del paso 1
syntax = "proto3";

package biblioteca;

service Biblioteca {
  rpc BuscarLibro (LibroRequest) returns (Libro);
  rpc ListarPorAutor (AutorRequest) returns (stream Libro);
}

message LibroRequest {
  string clave = 1;
}

message AutorRequest {
  string autor = 1;
}

message Libro {
  string clave = 1;
  string titulo = 2;
  string autor = 3;
  int32 paginas = 4;
}

Paso 2 · Compilar

  • Corre python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. biblioteca.proto
  • Comprueba con ls que aparecieron biblioteca_pb2.py y biblioteca_pb2_grpc.py.
  • Abre biblioteca_pb2_grpc.py y busca tres nombres: BibliotecaStub, BibliotecaServicer y add_BibliotecaServicer_to_server. Son los que vas a usar.

Paso 3 · El servidor unario

  • Importa grpc, futures y los dos archivos generados.
  • Un diccionario LIBROS con los tres libros.
  • Una clase que hereda de BibliotecaServicer con el método BuscarLibro(self, request, context).
  • Las dos validaciones con context.abort y el return de un biblioteca_pb2.Libro.
  • Al final: crear el servidor, registrar tu clase, abrir el puerto 50070, start() y wait_for_termination().
Pista 1 · el orden del método
Primero lo que no tiene sentido (vacío → INVALID_ARGUMENT), luego lo que no existe (NOT_FOUND), y al final el return. Después de un context.abort el método ya no sigue.
Pista 2 · las últimas 5 líneas
servidor = grpc.server(futures.ThreadPoolExecutor(max_workers=10))
biblioteca_pb2_grpc.add_BibliotecaServicer_to_server(BibliotecaServicio(), servidor)
servidor.add_insecure_port("[::]:50070")
servidor.start()
servidor.wait_for_termination()
Si olvidas la línea de add_…_to_server, el servidor corre, pero el cliente recibe UNIMPLEMENTED: Method not found!

Paso 4 · El cliente, con el error atrapado

  • Un canal a localhost:50070 y un BibliotecaStub (no el Servicer).
  • Llamada 1 con L001: imprime título, autor y páginas.
  • Llamada 2 con L999 dentro de try/except grpc.RpcError: imprime e.code().name y e.details().
  • Pruébalo: terminal 1 el servidor, terminal 2 el cliente.
Pista 1
El stub se crea con el canal: stub = biblioteca_pb2_grpc.BibliotecaStub(canal). La petición es una caja de biblioteca_pb2: biblioteca_pb2.LibroRequest(clave="L001").

Paso 5 · El streaming

  • En el servidor, ListarPorAutor busca los libros del autor; si no hay ninguno, NOT_FOUND.
  • Por cada libro: time.sleep(0.5) y yield (no return).
  • Reinicia el servidor (Ctrl + C) antes de probar.
  • En el cliente, recórrelo con for dentro de try/except. Prueba también con un autor que no existe.
Pista 1
Para buscar por autor: encontrados = [(c, d) for c, d in LIBROS.items() if d[1] == request.autor]. Cada yield es una caja que sale en ese momento; cuando el método termina, gRPC manda solo el aviso de fin.
Ver la solución completa (servidor y cliente)
# servidor.py
import time
from concurrent import futures

import grpc

import biblioteca_pb2
import biblioteca_pb2_grpc

LIBROS = {
    "L001": ("Pedro Paramo", "Rulfo", 124),
    "L002": ("El llano en llamas", "Rulfo", 170),
    "L003": ("Aura", "Fuentes", 61),
}


class BibliotecaServicio(biblioteca_pb2_grpc.BibliotecaServicer):

    def BuscarLibro(self, request, context):
        if request.clave == "":
            context.abort(grpc.StatusCode.INVALID_ARGUMENT, "La clave es obligatoria")
        if request.clave not in LIBROS:
            context.abort(grpc.StatusCode.NOT_FOUND, f"No existe el libro {request.clave}")
        titulo, autor, paginas = LIBROS[request.clave]
        return biblioteca_pb2.Libro(clave=request.clave, titulo=titulo,
                                    autor=autor, paginas=paginas)

    def ListarPorAutor(self, request, context):
        encontrados = [(c, d) for c, d in LIBROS.items() if d[1] == request.autor]
        if not encontrados:
            context.abort(grpc.StatusCode.NOT_FOUND, f"No hay libros de {request.autor}")
        for clave, (titulo, autor, paginas) in encontrados:
            time.sleep(0.5)
            yield biblioteca_pb2.Libro(clave=clave, titulo=titulo,
                                       autor=autor, paginas=paginas)


servidor = grpc.server(futures.ThreadPoolExecutor(max_workers=10))
biblioteca_pb2_grpc.add_BibliotecaServicer_to_server(BibliotecaServicio(), servidor)
servidor.add_insecure_port("[::]:50070")
servidor.start()
print("Biblioteca escuchando en el puerto 50070...")
servidor.wait_for_termination()
# cliente.py
import grpc

import biblioteca_pb2
import biblioteca_pb2_grpc

canal = grpc.insecure_channel("localhost:50070")
stub = biblioteca_pb2_grpc.BibliotecaStub(canal)

print("=== 1 · Un libro que existe ===")
libro = stub.BuscarLibro(biblioteca_pb2.LibroRequest(clave="L001"))
print(libro.titulo, "-", libro.autor, "-", libro.paginas, "páginas")

print("=== 2 · Un libro que no existe ===")
try:
    stub.BuscarLibro(biblioteca_pb2.LibroRequest(clave="L999"))
except grpc.RpcError as e:
    print("Error:", e.code().name, "-", e.details())

print("=== 3 · Todos los libros de Rulfo (streaming) ===")
try:
    for libro in stub.ListarPorAutor(biblioteca_pb2.AutorRequest(autor="Rulfo")):
        print("Llegó:", libro.titulo)
except grpc.RpcError as e:
    print("Error:", e.code().name, "-", e.details())
