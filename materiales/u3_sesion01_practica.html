05

Laboratorio: tu libro en una API real

Pendiente

En tu VS Code. Baja api_libros.py y ver_http.py de Classroom a una carpeta nueva y abre esa carpeta. Vas a necesitar dos terminales.

pip install fastapi uvicorn
uvicorn api_libros:app --reload        ← terminal 1 (déjala corriendo)

Abre http://127.0.0.1:8000/docs. En cada endpoint: Try it out, llena los datos y Execute. Usa tu matrícula como id del libro. Haz la misión en este orden:

#Haz estoEsperas
1POST /libros con id = tu matrícula, un título y un autor201
2Terminal 2: python ver_http.py /libros/TU_MATRICULA · mira el mensaje crudo que manda y el que recibe200
3El mismo POST del paso 1 otra vez409
4POST /libros con tu matrícula pero sin titulo422
5PUT /libros/{tu matrícula} dos veces con los mismos datos · ¿cambió la foto la segunda vez?200 · 200
6PATCH /libros/{tu matrícula} solo con "anio"200
7POST /libros/{tu matrícula}/prestamos dos veces · fíjate en el número de préstamo201 · 201
8DELETE /libros/{tu matrícula} con x-token vacío401
9El DELETE con x-token = alumno403
10El DELETE con x-token = bibliotecario dos veces204 · 404
11GET /bitacora/{tu matrícula} · copia toda la respuesta200
Si detienes el servidor o modificas el archivo, la bitácora se borra y hay que repetir la misión. Si uvicorn o pip no se reconocen, usa python -m uvicorn api_libros:app --reload y python -m pip install fastapi uvicorn. Los 401 y 403 los entenderemos a fondo en la sesión del login; hoy solo obsérvalos.
06

Ficha del proyecto de tu equipo

Pendiente

Llénenla juntos en una sola computadora. Después, “Copiar ficha para mi equipo”, y cada integrante la pega en “Importar”, para que todos la lleven igual en su PDF.

Ver el ejemplo resuelto: préstamo de equipo del laboratorio de Telemática

Problema: los préstamos de multímetros y Arduinos se anotan en una libreta y nadie sabe quién tiene qué ni cuándo lo devuelve. Usuarios: alumnos y el encargado del laboratorio. Recursos: equipos, prestamos, usuarios.

DELETE/prestamos/{id}Cancelar un préstamo204403, 404

Endpoint que debe ser idempotente: la devolución. Dice “déjalo devuelto”, así que un doble clic no registra dos devoluciones.
