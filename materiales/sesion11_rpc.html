Encuentra las piezas en código RMI real

Es el mismo ejemplo de la clase, ahora con letras en vez de etiquetas. No tienes que escribir Java: solo reconocer qué hace cada bloque. Tienes un intento por pregunta.

A
public interface Calculadora extends Remote {
    int sumar(int a, int b) throws RemoteException;
}
B
class CalculadoraImpl extends UnicastRemoteObject implements Calculadora {
    public int sumar(int a, int b) { return a + b; }
}
C
Registry registro = LocateRegistry.createRegistry(1099);
registro.rebind("calc", new CalculadoraImpl());
D
Calculadora calc = (Calculadora) LocateRegistry
    .getRegistry("localhost", 1099).lookup("calc");
E
int r = calc.sumar(2, 3);   // Resultado: 5

Deja listo tu laboratorio de gRPC

Es el mismo flujo de Codespaces que ya usaste en la sesión 07 y en el reto de la Unidad I, con otro repositorio. Este laboratorio lo usarás de la sesión 12 a la 16.

  1. Abre el repositorio plantilla desde el enlace publicado en Classroom (Sesión 11).
  2. Botón verde Use this template → Create a new repository. Nómbralo grpc-TU_MATRICULA.
  3. En tu copia: Code → Codespaces → Create codespace on main. La primera vez tarda 2–3 minutos: al final se instala gRPC solo.
  4. En la terminal del Codespace, escribe (con tu matrícula real):
python verificar_entorno.py TU_MATRICULA
Si algo sale mal (errores reales, ya resueltos)

Debe responder: 1) qué problema resolvía, 2) por qué quedó atrás, 3) qué se usa hoy en su lugar. Usa una analogía de la vida cotidiana y no más de 80 palabras en total.
