¿Quién es quién en el código?

Este es el código de servidor.py y cliente.py de tu Codespace. Para cada línea, elige qué es en el restaurante y presiona "Revisar".

servidor.py

class SaludadorServicio(
    saludo_pb2_grpc.SaludadorServicer):
  def SaludarUno(self, request, context):
    mensaje = f"Hola, {request.nombre}!"
    return saludo_pb2.SaludoResponse(
        mensaje=mensaje)

servidor = grpc.server(
    futures.ThreadPoolExecutor(max_workers=4))
saludo_pb2_grpc.add_SaludadorServicer_to_server(
    SaludadorServicio(), servidor)
servidor.add_insecure_port("[::]:50051")
servidor.start()
servidor.wait_for_termination()

cliente.py

canal = grpc.insecure_channel(
    "localhost:50051")
stub = saludo_pb2_grpc.SaludadorStub(canal)
respuesta = stub.SaludarUno(
    saludo_pb2.SaludoRequest(nombre="Ana"))
print(respuesta.mensaje)

Laboratorio: tu servidor responde con tu matrícula

En tu Codespace (github.com/codespaces → tu Codespace → Open). Necesitas dos terminales (ícono + del panel de terminal). Tu saludo.proto debe tener el campo string matricula = 2; de la sesión 12; si no lo tiene, agrégalo dentro de SaludoRequest.

  1. Compila y prueba tal como está. En la terminal 1:
bash compilar.sh && python servidor.py
  1. En la terminal 2 (con el servidor corriendo):
python cliente.py
  1. Misión 1 · cliente.py: manda tu nombre y tu matrícula (entre comillas):
saludo_pb2.SaludoRequest(nombre="Tu nombre", matricula="TU_MATRICULA")
  1. Misión 2 · servidor.py: dentro de SaludarUno (con la misma sangría que la línea mensaje = ...: 8 espacios), imprime lo que llega:
print(f"Llego una peticion: nombre={request.nombre}, matricula={request.matricula}")
  1. Misión 3 · servidor.py: el cocinero hace trabajo real. Antes del return, calcula la suma de los dígitos y úsala en el mensaje:
suma = sum(int(d) for d in request.matricula if d.isdigit())
mensaje = f"Hola, {request.nombre}! Los digitos de tu matricula {request.matricula} suman {suma}."
  1. Detén el servidor con Ctrl+C, vuelve a correrlo y después corre el cliente. Si no lo reinicias, sigue corriendo la versión vieja.
Si algo sale mal (errores reales, ya resueltos)
status = StatusCode.UNAVAILABLE ... Connection refusedEl servidor no está corriendo o el cliente usa otro puerto. Primero la terminal 1, después la 2.
status = StatusCode.UNIMPLEMENTED details = "Method not implemented!"El método no se llama exactamente SaludarUno.
ValueError: Protocol message SaludoRequest has no "matricula" field.Tu .proto no tiene el campo o no recompilaste: agrégalo y corre bash compilar.sh.
TypeError: bad argument type for built-in operationPasaste la matrícula sin comillas. Es string: matricula="20201234".
status = StatusCode.INTERNAL details = "Failed to serialize response!"Tu método regresó un texto. Debe regresar saludo_pb2.SaludoResponse(mensaje=mensaje).
IndentationError: unexpected indentLa línea nueva no tiene la misma sangría que las demás dentro de SaludarUno (8 espacios).
…suman 0. (y la matrícula sale vacía)El cliente no mandó la matrícula: revisa la Misión 1. Un campo que no se envía llega vacío, sin error.
