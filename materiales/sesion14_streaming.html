Laboratorio: un mensaje por cada dígito de tu matrícula

En tu Codespace (github.com/codespaces → tu Codespace → Open), con dos terminales. El orden importa: .proto → compilar → servidor (reiniciar) → cliente.

  1. saludo.proto: dentro de service Saludador, debajo de la línea de SaludarUno, agrega:
rpc SaludarVarios (SaludoRequest) returns (stream SaludoResponse);
  1. Guarda y compila en la terminal 1:
bash compilar.sh
  1. servidor.py: en la primera línea del archivo agrega import time. Después, dentro de la clase SaludadorServicio y debajo de SaludarUno (con 4 espacios antes de def), pega el método nuevo:
    def SaludarVarios(self, request, context):
        for i in range(1, 4):
            time.sleep(1)
            yield saludo_pb2.SaludoResponse(mensaje=f"Saludo {i} de 3 para {request.nombre}")
  1. Terminal 1: si el servidor ya estaba corriendo, detenlo con Ctrl+C. Luego vuelve a correrlo:
python servidor.py
  1. Archivo nuevo cliente_varios.py (en el explorador de archivos: clic derecho → New File). Pega esto y cambia el nombre y la matrícula por los tuyos:
import grpc

import saludo_pb2
import saludo_pb2_grpc

canal = grpc.insecure_channel("localhost:50051")
stub = saludo_pb2_grpc.SaludadorStub(canal)

peticion = saludo_pb2.SaludoRequest(nombre="Tu nombre", matricula="TU_MATRICULA")
for respuesta in stub.SaludarVarios(peticion):
    print("Llego:", respuesta.mensaje)
print("Fin del stream")
  1. Terminal 2: python cliente_varios.py. Deben llegar 3 saludos, uno cada segundo.
  1. Misión · servidor.py: cambia el cuerpo de SaludarVarios para que mande un mensaje por cada dígito de la matrícula:
    def SaludarVarios(self, request, context):
        print(f"Peticion de streaming: nombre={request.nombre}, matricula={request.matricula}")
        digitos = [d for d in request.matricula if d.isdigit()]
        for i, d in enumerate(digitos, start=1):
            time.sleep(0.5)
            yield saludo_pb2.SaludoResponse(mensaje=f"Digito {i} de {len(digitos)}: {d}")
  1. Reto (lo escribes tú): después del ciclo, con 8 espacios de sangría, agrega un yield más con la suma de los dígitos. Pista: la línea suma = ... de la sesión 13. Debe imprimirse algo como Llego: Listo, Ana: tus digitos suman 14.
  2. Ctrl+C, vuelve a correr el servidor y después el cliente.
